# For Claude Code users
Read `AGENTS.md`, `PROJECT.md`, `docs/CONTRACT.md`, `docs/TEAM.md`, and the matching task under `tasks/` before making any code changes. Follow exact branch ownership and the 3-hour hackathon scope.

This is an initialized, key-free starter. Do not re-scaffold it or implement another owner's feature. Shared configuration and contract edits go through Gjin. Run `npm run typecheck`, `npm run lint`, `npm run build`, then `npm test`. Push only your feature branch and open a small PR to main. Gjin handles invitations, secrets and Vercel manually; never deploy or create accounts merely because a task document describes the future launch.
